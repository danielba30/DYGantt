# DYGantt — מיני גאנט

מערכת Web עצמאית לבניית לוחות גאנט לפרויקטים, בקובץ `index.html` יחיד — בלי שרת, בלי התקנה ובלי ספריות חיצוניות (למעט Tailwind CSS ו-Google Fonts מ-CDN).

## הפעלה

מורידים את `index.html` ופותחים אותו בדפדפן. זהו.

אפשר גם לפרוס לאתר סטטי (Vercel, Netlify, GitHub Pages) — אין צורך ב-build, בשרת או במסד נתונים. בפריסה כזו גם `localStorage` עובד יציב, בניגוד לפתיחה מקומית מ-`file://`.

## יכולות

**הגדרות פרויקט**
- תאריך התחלה, שם פרויקט
- יחידת זמן ברמת הפרויקט: ימים (כולל עשרוניים, למשל 1.5) או שעות, עם תקן שעות ליום עבודה (ברירת מחדל 8.5)
- ימי חופשה כתאריך בודד או כטווח, עם הערה חופשית לכל חופשה

**לוגיקת תזמון**
- שבוע עבודה ישראלי: ראשון–חמישי. שישי, שבת וימי חופשה מדולגים אוטומטית
- תלות Finish-to-Start: משימה חדשה נתלית כברירת מחדל בקודמת, וניתן לשנות לכל משימה קודמת או ל"ללא תלות"
- שרשור רציף: משימה תלויה ממשיכה בדיוק מנקודת הסיום של קודמתה, כולל אמצע יום

**משימות**
- שם, אחריות, משך, תלות והערות
- אפשרויות האחריות ניתנות להגדרה: הוספה, שינוי שם, מחיקה וקביעת ברירת מחדל — עד 8 אפשרויות, כל אחת בצבע משלה

**פעולות שורה**
- בריחוף מעל שורה מופיעים שני אייקונים: עיפרון (עריכה) ו-X (מחיקה); במסכי מגע הם תמיד גלויים
- עריכה פותחת חלון עם כל שדות המשימה: שם, אחריות, סטטוס, משך, תלות והערות
- מחיקה מציגה אישור "האם אתה בטוח?" לפני שהשורה נמחקת, ומציינת כמה משימות תלויות בה
- הוספת שורה באמצע: האייקון ＋ בשורה מוסיף משימה חדשה ישר מתחתיה, והשורה שאחריה ממשיכה ממנה — השרשרת נשמרת
- גרירת שורות: אוחזים בידית (המספר הופך לאייקון גרירה בריחוף) וגוררים למקום החדש; קו כחול מראה היכן היא תיפול
- בהעברה השורה מתחברת לשורה שמעליה במקומה החדש, והשורות שהיו תלויות בה ממשיכות מהקודמת שלה — כך הגאנט נשאר רציף
- תאריך התחלה: למשימה ללא תלות אפשר לקבוע תאריך התחלה בתא התאריכים או בחלון העריכה; שישי, שבת וחופשה נדחים ליום העבודה הבא. למשימה תלויה התאריך מחושב אוטומטית
- במצב צפייה כל הכפתורים והגרירה אינם קיימים

**סטטוס משימה**
- עמודת "סטטוס" עם חמישה ערכים: ממתין, בתהליך, בבדיקה, חסום, הסתיים — כל אחד בצבע משלו
- בגאנט: משימה שהסתיימה מוצגת דהויה עם סימן ✓, ומשימה חסומה מוקפת במסגרת אדומה
- בסרגל הסיכום: מד התקדמות "הושלמו X מתוך Y" ומונה משימות חסומות

**תצוגה**
- טבלה מימין ויומן משמאל, מסונכרנים
- עמודות הטבלה ניתנות לגרירה — שינוי סדר וגם שינוי רוחב
- ציר הזמן נגרר ימינה ושמאלה עם העכבר
- ימי מנוחה וחופשה מסומנים באפור לאורך כל הגאנט, ימים חלקיים מוצגים במילוי חלקי

**ריבוי פרויקטים**
- לשוניות פרויקטים בראש הדף: מעבר בקליק, פרויקט חדש, שכפול ומחיקה
- לכל פרויקט משימות, הגדרות, ימי חופשה ואפשרויות אחריות משלו — מבודדים לחלוטין זה מזה
- שם הפרויקט נערך בשדה "שם הפרויקט" ומתעדכן מיד בלשונית
- פרויקטים שנשמרו בגרסה קודמת (פרויקט בודד) עוברים אוטומטית למבנה החדש בלי לאבד נתונים

**שיתוף ללקוח**
- כפתור "שיתוף ללקוח" יוצר קישור קצר וקבוע, למשל `https://dygantt-nu.vercel.app/#s=6i42ube9`
- הגאנט נשמר בענן (Vercel Blob פרטי), והקישור מצביע עליו — כל שינוי בפרויקט משותף נשמר אוטומטית גם בו, וצופה רואה את הגרסה העדכנית ברענון (הדף נבדק לבד כל 30 שניות)
- מי שפותח את הקישור רואה תצוגה בלבד: באנר עם שם הפרויקט וזמן העדכון האחרון, בלי כלי עריכה
- "הפסקת שיתוף" מוחקת את העותק בענן והקישור מפסיק לעבוד
- כתיבה ומחיקה בענן דורשות את סיסמת העריכה, והיא נבדקת בשרת (`api/share.js`); קריאה פתוחה לכל מי שיש לו את הקישור
- קישורים ארוכים ישנים (`#v=`) ממשיכים לעבוד כתמונת מצב

**נעילת עריכה**
- האפליקציה נפתחת במצב צפייה; עריכה דורשת סיסמה
- באתר המותקן הסיסמה נבדקת בשרת מול משתנה הסביבה `EDIT_PASSWORD` (מקור האמת). בפתיחה מקובץ מקומי אין נעילה
- אם השרת לא זמין, נבדקת טביעת אצבע מקומית (SHA-256) כגיבוי; זהו מחסום ולא אבטחה, כי הגיבוב בקוד הדף
- אבטחה אמיתית קיימת בענן: אי אפשר לכתוב, לעדכן או למחוק קישור משותף בלי הסיסמה

**שמירה וייצוא**
- שמירה אוטומטית של כל הפרויקטים לקובץ `.gantt.json` מקומי (File System Access API), עם נפילה חלקה להורדה/העלאה בדפדפנים שאינם תומכים
- שמירה אוטומטית גם ב-localStorage, עם התראה כשהדפדפן חוסם אותה
- ייצוא לאקסל הכולל את הגאנט המלא בצבעים (SpreadsheetML)
- ייבוא משימות מ-`.xlsx`, `.xls`, `.csv` וטבלאות HTML, עם זיהוי אוטומטי של העמודות

## טכני

- RTL מלא ותמיכה בעברית
- קובץ HTML יחיד: HTML + JavaScript מודרני + Tailwind CSS
- ללא תלויות build, ללא שרת, רץ ישירות מ-`file://`

## פריסה והגדרת השרת

```bash
vercel blob create-store dygantt-shares --access private --region fra1 --yes   # חנות Blob פרטית, מחוברת לפרויקט
vercel env add EDIT_PASSWORD production                                         # סיסמת העריכה (בצד שרת בלבד)
vercel --prod --yes
```

- `api/auth.js` — בדיקת סיסמה; `api/share.js` — קריאה (GET), יצירה/עדכון (POST) ומחיקה (DELETE) של גאנט משותף
- שינוי הסיסמה: מעדכנים את `EDIT_PASSWORD` ופורסים מחדש
